# Проект ООП

## Этот проект реализует классы Prodict и Category

## Созданы два класса наследников класса Product «Смартфон» (Smartphone) и «Трава газонная» (LawnGrass).

### Функционал

* Класс Product - представляет товар с названием
* Класс Category - хранит список товаров и считает их количество
* Класса Product «Смартфон» - Класс «Смартфон» (Smartphone) расширен атрибутами: производительность (efficiency), модель (model), объем встроенной памяти (memory), цвет (color)
* Класс «Трава газонная» (LawnGrass) - Класс «Трава газонная» (LawnGrass) расширен атрибутами: страна-производитель (country), срок прорастания (germination_period), цвет (color).
